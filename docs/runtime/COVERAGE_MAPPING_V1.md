# Stage 6.2 Coverage Mapping

Status: GitHub Actions validated for Stage 6.2; freeze closure pending.

This step maps the configured coverage relationships already present in production. It does not decide whether the current board set is complete, does not identify missing boards, and does not add sources.

## Mapping semantics

`CONFIGURED` country coverage means the production configuration explicitly constrains a source to a country or search location, or the source is a fixed-country institution or portal.

`UNRESOLVED` geography means the source is intentionally left without invented country coverage because its listings are native, inferred per record, or board-wide without an explicit production country filter.

## Traceability

The machine-readable mapping is generated by `src/runtime/coverage_mapping.py` from the frozen Stage 6.1 inventory.

It provides three views:

- country to source/board/shard/institution
- board family to country/source/shard/institution
- institution to source/board/shard/country

Run:

`python scripts/verify_stage6_2_coverage_mapping.py`

The verifier is read-only and checks internal accounting and traceability only.
